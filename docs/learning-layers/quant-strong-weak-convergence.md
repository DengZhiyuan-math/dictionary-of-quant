# 强收敛与弱收敛

概念编号：`concept:quant-strong-weak-convergence` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-strong-weak-convergence/)

## 第一层：概念入门 · 知其然

### 它是什么

随机数值方法的强收敛比较同一驱动噪声下的路径误差，弱收敛比较某类测试函数的期望误差。定价均值接近，不表示每条模拟路径也接近。

### 先看一个例子

若步长减半，处在相应渐近区间时，强误差 0.04 预计约变为 0.04/√2≈0.0283，弱误差 0.02 约变为 0.01。做路径比较要共享同一布朗路径的聚合增量；独立抽两条路径会把真实随机差异误当离散误差。

## 第二层：深入理解 · 知其所以然

### 参数与公式

强误差可用 $E[|X_T-X_T^h|]$，弱误差可用 $|E[f(X_T)]-E[f(X_T^h)]|$；h 为时间步长，f 为指定测试函数。经典光滑、正则条件下，Euler–Maruyama 常具有强阶 1/2、弱阶 1，不能对任意模型和支付无条件套用。


### 适用边界与常见误解

增加路径数不解决网格偏差。
