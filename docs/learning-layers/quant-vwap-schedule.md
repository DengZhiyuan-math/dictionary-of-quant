# 成交量加权执行计划

概念编号：`concept:quant-vwap-schedule` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-vwap-schedule/)

## 第一层：概念入门 · 知其然

### 它是什么

VWAP 执行计划按事前预计的市场量曲线拆分目标交易量。基础 VWAP 是由成交价格和数量计算的加权均价；执行计划是下单规则，两者的输入和输出不同，采用该计划并不保证实现价格等于市场 VWAP。

### 先看一个例子

若第一桶只成交 60 股，如何处理剩余 40 股属于执行更新规则；事后再用真正发生的成交价和数量计算实现均价，不能把计划量当成真实成交。

## 第二层：深入理解 · 知其所以然

### 参数、公式与边界

预计第 j 个时间桶的市场量为 \(\widehat V_j\)，总目标量为 Q，则计划量为 \(q_j=Q\widehat V_j/\sum_k\widehat V_k\)。预计量须在计划时可得，且总预计量为正。计划如何随实际成交量偏差、未成交数量和约束更新，要事先约定，不能使用未来实际全日量重写历史计划。


### 例子

买入 1000 股，四桶预计量占比为 10%、20%、40%、30%，初始计划是 100、200、400、300 股。若第一桶只成交 60 股，如何处理剩余 40 股属于执行更新规则；事后再用真正发生的成交价和数量计算实现均价，不能把计划量当成真实成交。


### 适用边界与常见误解

事后真实全日量可评估基准，不能回填当日决策。
