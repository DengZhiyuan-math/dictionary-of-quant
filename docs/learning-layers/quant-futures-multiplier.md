# 期货乘数

概念编号：`concept:quant-futures-multiplier` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-futures-multiplier/)

## 第一层：概念入门 · 知其然

### 它是什么

期货乘数规定每张合约每一点价格变化对应多少货币金额，用来把点数报价转换成合约名义金额和损益。不同合约的单位可能不同，必须按合约规则确认。

### 先看一个例子

乘数为每点 50 元、价格 1,200 点，单张名义为 60,000 元。持有 4 张空头，价格从 1,200 跌至 1,190，损益为 (-4)×(-10)×50=2,000 元。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与公式

单张名义为 Fm，n 张的价格损益为 n(F₁-F₀)m。F₀、F₁ 是开平仓点数，m 是每点每张金额；n>0 为多头、n<0 为空头。保证金不是这里的乘数。


### 适用边界与常见误解

单张名义为 F×乘数，不是保证金。
