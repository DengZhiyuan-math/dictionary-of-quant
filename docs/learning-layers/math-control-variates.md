# 控制变量降方差

概念编号：`concept:math-control-variates` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/math-control-variates/)

## 第一层：概念入门 · 知其然

### 它是什么

控制变量利用一个期望已知、又与目标高度相关的辅助随机量，抵消样本中的部分波动。它改变估计器的随机误差，不改变待估计的理论期望。

### 先看一个例子

若 Y=2X+ε、E[X]=1、ε 与 X 独立且均值为零，取 β=2 后得到 Yᶜᵛ=2+ε，X 本身的波动被消除。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$Y^{cv}=Y-\beta(X-\mathbb E[X]),\qquad\beta^*=\operatorname{Cov}(Y,X)/\operatorname{Var}(X)$。

Y 是目标支付，X 是控制量，β 为调整系数；控制量必须有正确的已知期望且方差为正。实践中可用独立训练样本估计 β，再在评价样本应用。


### 适用边界

错误的控制量均值会引入偏差；使用同一小样本估计系数时还要检查有限样本误差。


### 适用边界与常见误解
