# Jensen 不等式

概念编号：`concept:prob-jensen` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/prob-jensen/)

## 第一层：概念入门 · 知其然

### 它是什么

Jensen 不等式比较“先取平均再做凸变换”和“先做凸变换再取平均”。凸函数下，后者不小于前者。

### 先看一个例子

两次读数是 1 和 3。先平均再平方得到 4；先平方再平均得到 5。平方曲线的弯曲使两种顺序产生不同结果。

### 理解练习

能否把平均值直接代入任意非线性函数，作为函数结果的平均？

<details><summary>答案与解释</summary>

一般不能。非线性变换与平均通常不能交换；凸性或凹性可以帮助判断差异方向。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 定义

Jensen 不等式把凸性与随机变量联系起来：先对变量求平均再代入凸函数，不会比先代入凸函数再求平均更大。这解释了非线性支付为何不能只用平均输入估值。


### 公式与参数

$f(E[X])\le E[f(X)]$，其中 f 是凸函数，相关期望存在。

X 是随机变量，f 是同一取值区间上的凸函数。若 f 为凹函数，方向反转；严格凸情形下，非退化随机性通常导致严格不等式。


### 例子

X 等概率取 0 和 2，f(x)=x²，则 f(E[X])=1，而 E[f(X)]=2。用均值代替整个随机分布会漏掉曲率带来的贡献。


### 适用边界

不能不检查凸性就判断方向，也不能用这一不等式替代完整的风险中性定价条件。


### 适用边界与常见误解

不能不检查凸性就判断方向，也不能用这一不等式替代完整的风险中性定价条件。
