# 预期尾部损失

概念编号：`concept:quant-es-cvar` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-es-cvar/)

## 第一层：概念入门 · 知其然

### 它是什么

定义损失 L 越大越差，VaR 是指定分位阈值；ES/CVaR 描述相应上尾平均损失，含原子分布时不能简单只取严格大于分位值的观察。样本 CVaR 可写 min_eta[eta+Σmax(L_s-eta,0)/((1-α)M)]，便于与情景权重和优化结合。

### 先看一个例子

五个等概率损失为1、2、3、4、10，α=80%；用相应经验分位口径 VaR=4，最坏20%平均为10。上述优化式在 eta=4 时给4+(10-4)=10。该数字来自给定五个情景，未观察到的跳空不会自动包含在样本 ES 中。
