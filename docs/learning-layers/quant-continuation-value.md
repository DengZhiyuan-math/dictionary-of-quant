# 继续持有价值

概念编号：`concept:quant-continuation-value` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-continuation-value/)

## 第一层：概念入门 · 知其然

### 它是什么

继续持有价值是在当前不行权、保留合约并按模型继续决策的价值。在树的节点上，它等于下一步各节点价值按风险中性概率加权再折现；比较立即行权价值，才能确定美式期权是否提前行权。

### 先看一个例子

若同节点折现继续价值仅 28，则美式取 30、欧式仍取 28。各节点比较都必须用该节点当时可得状态，不能先看完整未来路径再挑最佳时点。
