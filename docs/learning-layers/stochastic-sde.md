# 随机微分方程

概念编号：`concept:stochastic-sde` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/stochastic-sde/)

## 第一层：概念入门 · 知其然

### 它是什么

随机微分方程用漂移和随机扰动描述状态的连续时间演化。解是一个随机过程；即使初值相同，不同噪声路径也会产生不同结果。

### 先看一个例子

在加性模型 dX=2dt+3dW 中，初值 10、步长 0.01、抽到 Z=−1，则下一步为 10+0.02−0.3=9.72。漂移与随机增量分别按 Δt 与其平方根缩放。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$dX_t=\mu(t,X_t)dt+\sigma(t,X_t)dW_t,\quad X_{n+1}=X_n+\mu(t_n,X_n)\Delta t+\sigma(t_n,X_n)\sqrt{\Delta t}Z_n$。

μ 是单位时间的条件平均变化率，σ 是扩散系数，W 是布朗运动，Z 为独立标准正态数。第二式是 Euler–Maruyama 离散近似，并非一般方程的精确解。
