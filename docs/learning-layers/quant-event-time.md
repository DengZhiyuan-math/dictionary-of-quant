# 事件发生时间

概念编号：`concept:quant-event-time` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-event-time/)

## 第一层：概念入门 · 知其然

### 它是什么

事件发生时间是行情、成交等事件在来源端实际发生或被来源端标记的时间。它与本地收到消息的时间不同；研究中的事件时钟也可能指按事件序号推进，二者需按语境区分。

### 先看一个例子

若时钟可比，消息延迟为 3 毫秒；10:00:00.002 的本地决策不能读取这条未来才到的行情。

### 参数与关系

设发生时间 t_e、接收时间 t_r，传输与接收前排队延迟可概括为 t_r-t_e，但跨机时间差必须考虑时钟同步误差。策略在 t_r 之前通常不能使用该消息。


### 例子

场所事件标记 10:00:00.001，本地 10:00:00.004 才收到。若时钟可比，消息延迟为 3 毫秒；10:00:00.002 的本地决策不能读取这条未来才到的行情。


### 适用边界与常见误解

不等于本地已经收到信息的时刻。
