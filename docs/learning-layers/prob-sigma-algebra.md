# σ 代数与可测信息

概念编号：`concept:prob-sigma-algebra` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/prob-sigma-algebra/)

## 第一层：概念入门 · 知其然

### 它是什么

σ 代数是一组事件集合，描述某一信息状态下可以判断真假的事件。它对补集和可数并封闭，因此能够在这些事件上连贯地定义概率与条件期望。

### 先看一个例子

掷一次骰子，只告诉你奇偶性时，可以判断的非平凡事件是 {1,3,5} 和 {2,4,6}，却不能判断是否恰好为 5。这份信息比完整点数更粗。

### 公式与参数

$\Omega\in\mathcal F,\quad A\in\mathcal F\Rightarrow A^c\in\mathcal F,\quad A_n\in\mathcal F\Rightarrow\bigcup_{n\ge1}A_n\in\mathcal F$。

Ω 是所有可能结果，𝓕 是允许观察的事件族。随机变量对 𝓕 可测，表示它的取值可以由这份信息判断；随时间增长的一族信息是滤过。


### 适用边界

σ 代数描述信息结构，不是某个事件的概率大小；条件期望也不要求观察者知道最终结果。
