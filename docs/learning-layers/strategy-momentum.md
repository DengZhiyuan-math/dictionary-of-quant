# 动量与趋势跟随

概念编号：`concept:strategy-momentum` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/strategy-momentum/)

## 第一层：概念入门 · 知其然

### 它是什么

横截面动量比较同一时点不同资产的历史表现，倾向买赢家、卖输家；时间序列趋势跟随把每个资产自己的过去变化与零或其他基准比较。它们的排序对象和持仓规则不同。

### 先看一个例子

A 从 100 涨到 112、B 从 100 涨到 105，横截面动量会把 A 排在 B 前；时间序列规则可能同时做多两者，因为两者各自收益均为正。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$m_{i,t}=P_{i,t}/P_{i,t-L}-1,\qquad w_{i,t}\propto\mathrm{sign}(m_{i,t})/\widehat\sigma_{i,t}$（一个趋势规则）。

P 为按目标统一处理分红与复权的价格，L 为回看长度，σhat 为当时可得的波动估计。还需明确调仓日、信号滞后、仓位上限和归一化方法。


### 适用边界

趋势反转、拥挤、融资及换手会改变净收益。不能用当日收盘才确定的信号，假设自己已在同一收盘前成交。
