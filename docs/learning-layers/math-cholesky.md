# Cholesky 分解

概念编号：`concept:math-cholesky` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/math-cholesky/)

## 第一层：概念入门 · 知其然

### 它是什么

Cholesky 分解把实对称正定矩阵写成一个下三角矩阵与其转置的乘积。它常用于解线性方程以及把独立标准正态变量变换为相关正态变量。

### 先看一个例子

Σ=[[4,2],[2,5]] 可取 L=[[2,0],[1,2]]。令 X₁=2Z₁、X₂=Z₁+2Z₂，就得到方差 4、5 和协方差 2。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$\Sigma=LL^\top,\qquad X=\mu+LZ,\quad Z\sim N(0,I)$。

Σ 是协方差矩阵，正定表示任意非零向量 z 都有 zᵀΣz>0。L 为主对角线上方全为零、对角线取正值的下三角因子，μ 为均值向量。I 是单位矩阵；因为 Cov(Z)=I，X 的协方差为 Σ。


### 适用边界

普通 Cholesky 要求正定；奇异、近奇异或估计误差导致的非正定协方差，需要先检查数据与矩阵条件。
