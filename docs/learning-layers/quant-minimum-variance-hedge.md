# 最小方差套保

概念编号：`concept:quant-minimum-variance-hedge` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-minimum-variance-hedge/)

## 第一层：概念入门 · 知其然

### 它是什么

最小方差套保是选择代理持仓，使被套保资产与代理组合之后的残余收益方差尽可能小。这个目标降低模型内的总体波动，不自动最小化费用、最坏损失或保证金需求。

### 先看一个例子

设 ΣH=[[4,1],[1,4]]、c=(2.3,1.7)，统一相同收益尺度，解得 h=(0.5,0.3)。100 万元资产多头对应卖出两个代理名义 50 万元与 30 万元；比例之和不需要为 1。代理高度相关时求解可能不稳定，仍需检验样本、成本和限额。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与公式

若残余收益为 rE-hᵀrH，则最小化 Var(rE-hᵀrH) 的一阶条件为 ΣH h=c；ΣH 是代理收益协方差矩阵，c 是各代理与目标资产的协方差向量。矩阵可逆时 h=ΣH⁻¹c；单代理退化为 h=Cov(rE,rH)/Var(rH)。对多头资产，实际代理名义方向为 -hN。


### 适用边界与常见误解

不自动最小化成本或尾部损失。
