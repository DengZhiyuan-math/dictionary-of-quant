# 库存惩罚

概念编号：`concept:quant-inventory-penalty` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-inventory-penalty/)

## 第一层：概念入门 · 知其然

### 它是什么

报价者要在赚取交易价格优势、承担库存价格风险和是否能成交之间权衡。模型状态可含现金x、库存q、中价s与剩余期限τ，目标可能是终端效用或带库存惩罚的期望收益。相同公平价值下，不同库存与资金容量会给出不同报价。

公平价值预测、个人保留价格与实际发布报价是三个量。保留价格反映库存偏好，不是可以保证成交的市场价格。

### 先看一个例子

例如s=100、q=2、γ=.1、σ²τ=.04，则库存调整.008，r=99.992。将q改成-2得到100.008。这里q按单位合约计，若实际一张代表100股，风险暴露与参数都需一致换算。

### 保留价格的方向与单位

在算术Brownian中价、指数效用等简化设定中，常用保留价格r=s-qγσ²τ。σ是货币价格每根号时间的波动，γ与财富效用尺度相容，不能直接填年化百分比波动而不转换。长库存q>0使r向下，倾向减少买入、促进卖出。

例如s=100、q=2、γ=.1、σ²τ=.04，则库存调整.008，r=99.992。将q改成-2得到100.008。这里q按单位合约计，若实际一张代表100股，风险暴露与参数都需一致换算。
