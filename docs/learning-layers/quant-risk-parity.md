# 风险平价

概念编号：`concept:quant-risk-parity` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-risk-parity/)

## 第一层：概念入门 · 知其然

### 它是什么

风险平价通过权重使各资产或风险组的风险贡献满足指定比例，常见特例是等波动贡献。若 σp=√(wᵀΣw)，第 i 项贡献为 RCᵢ=wᵢ(Σw)ᵢ/σp；资金等权一般不满足 RC 相等。

### 风险平价与 GMV 不相同

两资产波动20%与10%、相关0，等波动贡献的权重为 A1/3、B2/3，因为两边 wσ 相等；GMV 则 A0.2、B0.8。逆波动权重在这个特殊结构下得到等风险贡献，但一般相关矩阵下不应视为普遍闭式。


### 适用边界与常见误解

一般相关结构下不等于简单逆波动。

### 概念辨析

- [Max-min Fairness / Water Filling](https://github.com/DengZhiyuan-math/dictionary-of-computer-science-and-AI/blob/main/docs/learning-layers/max-min-fairness.md)：最大最小公平分配保护较小的未满足分配；风险平价约束组合风险贡献。目标、单位与约束不同。
- [HRP · 聚类树的组合配置应用](portfolio-hrp.md)：等风险贡献要求各项风险贡献相等；HRP 沿聚类树递归分配权重，一般不保证每个资产的贡献相等。
