# 统计套利

概念编号：`concept:quant-statistical-arbitrage` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-statistical-arbitrage/)

## 第一层：概念入门 · 知其然

### 它是什么

统计套利用历史与模型关系形成有风险的相对价值判断，可能依赖均值回归、共同因子或暂时供需。它通常不能像理想无套利复制那样锁定每条路径的非负收益。名称中的套利不消除结构变化、参数误差、资金与执行风险。

输入包括当时可交易股票池、价格与基本信息、关系模型、标签和约束；输出是有方向和规模的双腿或多腿交易计划，以及冻结样本外证据。

### 先看一个例子

假设，在形成期估计，在后续交易期按预定规则执行；报告所有试验、失败配对、交易成本、实际暴露与压力结果。案例只使用人为植入关系的两条合成价格，不据此声称在真实股票上发现稳定套利。第122至128讲依次建立统计、信号、交易与账本接口。

长10股Y、短15股X是对价格关系斜率的对冲；若X和Y对市场因子的beta分别1和1.2，实际市场风险还要乘各自价格与beta计算。价格回归β、收益因子β和股数比虽都可写希腊字母，却不属于同一单位。把每个系数的被解释变量、输入单位和拟合窗口写在模型包里，能避免跨层误用。
