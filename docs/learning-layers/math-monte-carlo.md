# Monte Carlo 估计

概念编号：`concept:math-monte-carlo` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/math-monte-carlo/)

## 第一层：概念入门 · 知其然

### 它是什么

Monte Carlo 通过随机抽样后的样本平均估计期望。期权定价中可以模拟终端支付，再取贴现平均；一般统计问题中也可估计积分或事件概率。

### 先看一个例子

若支付样本标准差约 20，使用 10,000 条独立路径，均值标准误约为 0.2。把标准误降到 0.1，通常需要约 40,000 条路径。

### 公式与参数

$\hat\mu_N=\frac1N\sum_{i=1}^NY_i,\qquad \widehat{SE}=s_Y/\sqrt N$。

Yᵢ 是独立同分布样本，N 是抽样次数，sᵧ 是样本标准差。标准误衡量估计均值的随机误差，和单个支付本身的标准差不同。


### 适用边界

平方根收敛依赖独立性与有限方差；路径离散误差和模型误差不包含在这个标准误中。
