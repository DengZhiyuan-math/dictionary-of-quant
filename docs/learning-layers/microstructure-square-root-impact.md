# 平方根市场冲击

概念编号：`concept:microstructure-square-root-impact` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/microstructure-square-root-impact/)

## 第一层：概念入门 · 知其然

### 它是什么

平方根冲击是一种经验尺度关系：一个较大母单对价格的影响，常随其占同期市场成交量比例的平方根增长。它描述特定样本和测量口径下的规律，不能当作所有订单的精确定律。

### 先看一个例子

σ=2%、Q/V=1%、Y=0.8 时，估计冲击为 0.8×0.02×0.1=0.0016，即 16 个基点。参与率加倍时，此式给出约 √2 倍冲击，而非两倍。

### 公式与参数

$I\approx Y\sigma\sqrt{|Q|/V}$。

I 是相对价格变化幅度，Q 为母单数量，V 为对应市场成交量，σ 为相同时间尺度的收益波动，Y 为经验系数。方向由买卖符号另行指定，还要区分峰值与永久冲击。

执行速度、流动性状态、其他交易者和母单识别方法都会影响估计。单位时间与成交量窗口不一致时，数值没有可比性。
