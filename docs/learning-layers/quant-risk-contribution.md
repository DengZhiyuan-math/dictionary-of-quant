# 风险贡献

概念编号：`concept:quant-risk-contribution` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-risk-contribution/)

## 第一层：概念入门 · 知其然

### 它是什么

风险贡献把组合整体风险按资产拆分。波动贡献同时依赖自身波动、权重和与其他资产的共同变化，所以资金权重相等不保证风险贡献相等。

### 先看一个例子

两资产不相关、波动率 10% 与 20%，各配 50%。组合方差为 0.0125、波动约 11.18%；两项波动贡献约为 2.24% 与 8.94%，相加为 11.18%。第二项占风险约 80%，不是 50%。

## 第二层：深入理解 · 知其所以然

### 参数与公式

组合波动 $\sigma_p=\sqrt{w^\top\Sigma w}$，资产 i 的边际波动贡献为 $(\Sigma w)_i/\sigma_p$，总波动贡献为 $RC_i=w_i(\Sigma w)_i/\sigma_p$，各项之和为 σp。要求 σp>0；空头或负相关可能产生负贡献。


### 适用边界与常见误解

等资金不等于等风险。
