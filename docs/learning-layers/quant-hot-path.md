# 交易热路径

概念编号：`concept:quant-hot-path` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-hot-path/)

## 第一层：概念入门 · 知其然

### 它是什么

热路径是系统中频繁执行、直接影响关键响应时间的一段处理链。哪些操作属于热路径由业务边界决定；低时延不等于可以跳过必要的风控与状态记录。

### 先看一个例子

行情解码 20 微秒、状态更新 15、特征计算 25、风控 10、编码发送 20，同一路径总计 90 微秒。把无关报表计算移到后台可能缩短响应；把必要风控移走则改变了准入语义，不能只按耗时评价。
