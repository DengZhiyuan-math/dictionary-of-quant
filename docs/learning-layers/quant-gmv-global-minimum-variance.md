# 全局最小方差组合

概念编号：`concept:quant-gmv-global-minimum-variance` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-gmv-global-minimum-variance/)

## 第一层：概念入门 · 知其然

### 它是什么

只最小化 wᵀΣw、预算和为 1 且无其他约束，拉格朗日一阶条件给 2Σw=λ1，归一化后 w_GMV=Σ^-1 1/(1ᵀΣ^-1 1)。Σ 正定时给唯一解；有做空限制或奇异矩阵时，不能直接套该闭式就当作最终答案。

### 先看一个例子

若 μ=(8%,4%)、γ=4，上述均值方差目标的 A 最优为 0.4、B0.6，预期回报 5.6%、波动 10%。 令A权重为x，目标导数为0.04-4(0.05x-0.01)，设为零即得x=0.4；这也说明系数1/2的约定会影响风险偏好参数。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 两资产的完整数值例子

A/B 年化波动 20%/10%、相关为 0，GMV 的 A 权重=0.01/(0.04+0.01)=0.2，B 为 0.8；波动 sqrt(0.2²×0.04+0.8²×0.01)≈8.9443%。若 μ=(8%,4%)、γ=4，上述均值方差目标的 A 最优为 0.4、B0.6，预期回报 5.6%、波动 10%。 令A权重为x，目标导数为0.04-4(0.05x-0.01)，设为零即得x=0.4；这也说明系数1/2的约定会影响风险偏好参数。


### 适用边界与常见误解

不同于风险平价或收益最大化。
