# 成交概率

概念编号：`concept:quant-fill-probability` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-fill-probability/)

## 第一层：概念入门 · 知其然

### 它是什么

成交概率是在明确时间窗口和市场条件下，一笔订单全部或部分成交的概率。必须先定义“成交”是至少成交一份、达到一定数量，还是全部完成。

### 先看一个例子

若吸引了更多知情对手，也可能降低成交后的条件收益。

### 参数与公式

设 F 为“期限内达到约定成交量”，则 p_fill=P(F|报价、数量、队列和市场信息)。一次机会的期望损益需按成交与不成交分支加权；简化为未成交损益为零时，E[Π]=p_fill E[Π|F]。


### 例子

某报价有 40% 概率成交，成交后的平均净收益为 0.05 元/份，未成交无损益，则每次机会的预期为 0.02 元/份。提高成交概率若吸引了更多知情对手，也可能降低成交后的条件收益。


### 适用边界与常见误解

提高成交率可能同时改变条件利润。
