# 强化学习的交易应用

概念编号：`concept:ml-rl-trading` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/ml-rl-trading/)

## 第一层：概念入门 · 知其然

### 它是什么

交易强化学习把市场和账户状态作为输入，把下单或目标仓位作为行动，依据后续净收益和风险代价学习策略。通用 Bellman 定义保留在强化学习基础页，这里明确金融环境中的状态与奖励。

### 先看一个例子

当前从零买入 2 单位，随后价格上涨 1，单位变仓成本 0.1、库存惩罚系数 0.05，则本期奖励为 2−0.2−0.2=1.6。忽略成本会改变最优行为。

### 公式与参数

$r_{t+1}=h_t(S_{t+1}-S_t)-c|h_t-h_{t-1}|-\lambda h_t^2,\qquad J=E[\sum_t\gamma^tr_{t+1}]$。

h 为持仓，S 为价格，c 为变仓成本，λ 为库存惩罚，γ∈[0,1] 为折扣因子。市场状态只能包含当时可见的信息，成交模拟是环境的一部分。


### 适用边界

历史回放不能自动识别未发生行动的真实成交和冲击。离线分布偏移、环境非平稳和奖励投机都要用样本外与压力测试检查。
