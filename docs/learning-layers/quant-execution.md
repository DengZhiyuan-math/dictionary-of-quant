# 交易执行

概念编号：`concept:quant-execution` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-execution/)

## 第一层：概念入门 · 知其然

### 它是什么

交易执行是把买卖意图转成订单并完成成交的过程，包括选择时间、场所、订单类型、价格和数量。模型认为便宜不代表能以模型价买到，执行结果还受到深度、排队、撤单和部分成交影响。

### 先看一个例子

买入 50,000 份，30,000 份在 100.10 成交，20,000 份在 100.20 成交，均价为 100.14。按最佳卖价 100.10 估算全部交易会低估 2,000 元成本。

### 参数与公式

成交均价 P̄=ΣQᵢPᵢ/ΣQᵢ。Qᵢ、Pᵢ 是各笔实际数量和价格。对买单，相对决策参考 P₀ 的价格成本为 ΣQᵢ(Pᵢ-P₀)；费用和未成交机会成本需要按预先定义的口径另外处理。


### 适用边界与常见误解

模型价、下单价和最终 fill 可能不同。
