# 秩信息系数

概念编号：`concept:quant-rank-ic` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-rank-ic/)

## 第一层：概念入门 · 知其然

### 它是什么

Rank IC 通常指信号与后续收益的 Spearman 秩相关。它先将两组观测各自转换为排序，再对秩计算 Pearson 相关，关注相对顺序而非原始数值的线性距离。它与原值上的 Pearson IC 不应混成一个数。

### 先看一个例子

信号为 (1,2,3)，后续收益为 (1%,2%,20%)，两组秩均为 (1,2,3)，所以 Rank IC=1；原值的 Pearson IC 则不会等于 1。大幅第三项改变了原值的线性距离，却没有改变顺序。这不是哪种指标必然更好，而是两种指标回答的问题不同。

### 参数、公式与边界

对同一截面样本，\(\mathrm{RankIC}=\operatorname{Corr}(\operatorname{rank}(s),\operatorname{rank}(r))\)。并列值常取平均秩，必须固定规则；完全常量的一组秩没有方差，此时相关未定义。应与普通 IC 使用相同的预测期限、样本范围和可见时间，才便于比较。
