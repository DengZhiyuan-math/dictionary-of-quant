# 预测期限

概念编号：`concept:quant-forecast-horizon` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-forecast-horizon/)

## 第一层：概念入门 · 知其然

### 它是什么

在每个起点只使用当时信息拟合或更新，分别评估h=1、5、20等期限。滚动与扩展窗口对应不同的偏差稳定性权衡。预测价格、收益、波动和隐状态的误差不可直接混成同一个排行榜，应先固定任务与基线。

评价对象至少要写出：预测起点、期限h、目标是水平还是变化、训练窗口、是否重拟合，以及损失函数。对于同一目标的模型A和B，用同一组起点逐一比较损失差，比把不同测试期的平均误差直接相比更有解释力。多期限结果应逐期限报告，不能只展示自己最强的期限。

### 先看一个例子

若把预测对象换成收益，仍需说明单位。预测区间的覆盖率和宽度应同时评价，区间越宽覆盖越高不是自动更好的预测。

MASE可用训练期朴素一步绝对误差作为尺度，把预测MAE除以该尺度；它避免部分量纲比较问题，但尺度的周期和计算窗口需要预先确定，分母接近零仍会不稳定。MAPE涉及除以实际值，对接近0或有正负的收益目标尤其不合适。基线不是装饰：若复杂模型输给最后值，应先诊断目标和可预测性。
