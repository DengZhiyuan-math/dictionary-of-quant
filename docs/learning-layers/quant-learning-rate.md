# 学习率

概念编号：`concept:quant-learning-rate` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-learning-rate/)

## 第一层：概念入门 · 知其然

### 它是什么

在金融提升树中，学习率控制每轮新树对已有预测的修正幅度。较小学习率通常需要更多轮训练；改变学习率而固定一个不足的轮数，可能把欠拟合误认为方法无效。候选学习率和最大轮数应提前规定，在按时间排列的验证段中比较。

### 先看一个例子

当前收益预测为 20 bps，新树建议修正 +10 bps，η=0.1 后预测变为 21 bps；η=0.5 时变为 25 bps。实际买多少仍由风险、成本和仓位映射决定。不能因为学习率是 0.1，就解释为应该投入 10% 资金；也不能根据最终测试收益倒挑这个数。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与更新单位

更新 \(F_{\mathrm{new}}=F_{\mathrm{old}}+\eta h\) 中，η 是无量纲缩放系数，h 是新树输出；若旧预测使用下一期收益的 bps，h 也必须是 bps。η 不是上涨概率，也不是资金投入比例。早停、树深与最小叶样本等同样影响容量，应纳入同一个选择流程。


### 适用边界与常见误解

小学习率本身不保证样本外有效。
