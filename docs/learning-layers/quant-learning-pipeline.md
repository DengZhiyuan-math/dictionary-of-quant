# 学习管线

概念编号：`concept:quant-learning-pipeline` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-learning-pipeline/)

## 第一层：概念入门 · 知其然

### 它是什么

金融训练管线把缺失填补、去极值、缩放、筛选、降维和模型拟合组织为可复现流程。输入除特征与标签，还应记录资产、可见时刻、单位和数据版本；输出应保留预处理参数、模型与训练截止。只保存最后一个预测器，不能复现完整决策。

### 先看一个例子

若先把 5 纳入统计，均值会变成 3，训练已经利用下一日信息。正确流程是先按日期分组切分，在训练内拟合整条管线，再对随后日期只做变换与预测。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与拟合范围

例如标准化 \(z=(x-\mu_{\mathrm{train}})/\sigma_{\mathrm{train}}\)，其中 x 是一个特征值，训练均值 μ 与正标准差 σ 由当前训练折估计。它们与模型参数一起在训练折内估计，随后冻结应用于验证或测试。每次滚动拟合都应重新建立当次参数；不能先在全历史计算均值、填补值或 PCA，再切分数据。


### 例子：验证日的数值不能改写训练均值

训练期某金融特征为 1、3，采用总体标准差口径时，均值为 2、标准差为 1；下一日输入 5，应变换为 3。若先把 5 纳入统计，均值会变成 3，训练已经利用下一日信息。正确流程是先按日期分组切分，在训练内拟合整条管线，再对随后日期只做变换与预测。
