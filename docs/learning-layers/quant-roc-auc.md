# 排序区分度

概念编号：`concept:quant-roc-auc` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-roc-auc/)

## 第一层：概念入门 · 知其然

### 它是什么

用 ROC AUC 评价金融模型时，可把未来指定期限上涨记为正类、其余记为负类，并明确零收益如何归类。AUC 关注上涨样本是否被排在下跌样本之前；它不检查分数是否等于真实概率，也不区分涨跌各自的金额。跨日期或跨资产汇总时，要说明比较的是哪一批样本。

### 先看一个例子

两笔未来上涨样本的分数为 0.9、0.4，两笔下跌样本为 0.6、0.2。四组正负比较中有三组顺序正确，没有并列，所以 AUC=3/4=0.75。但我们仍不知道每笔涨跌多少、按什么阈值下单、是否成交和成本多少。应在固定的时间外层测试中另行计算概率质量与交易结果。

### 成对比较公式与参数

经验 AUC 可写为 \(\frac{1}{n_+n_-}\sum_{i\in +}\sum_{j\in -}\left(\mathbf{1}\{s_i>s_j\}+0.5\mathbf{1}\{s_i=s_j\}\right)\)。s 是模型分数，\(n_+\)、\(n_-\) 分别为正负样本数；指示函数在条件成立时等于 1，否则为 0，相同分数计半次正确。只有一类的评价段不能用这个公式得到有效 AUC。


### 适用边界与常见误解

不直接衡量成本后利润或概率准确度。
