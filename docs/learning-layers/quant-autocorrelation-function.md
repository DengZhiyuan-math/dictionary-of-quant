# 自相关函数

概念编号：`concept:quant-autocorrelation-function` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-autocorrelation-function/)

## 第一层：概念入门 · 知其然

### 它是什么

自相关函数（ACF）描述同一平稳序列在相隔不同期数时的线性相关程度。在金融研究中，可以用它检查收益或模型残差是否仍有滞后相关。

### 先看一个例子

平稳 AR(1) 模型 y_t=0.8y_(t-1)+ε_t 中，创新互不相关时 ρ(k)=0.8^k，因此一期为 0.8、两期为 0.64。应只用当时训练窗口估计，随后检查样本外是否稳定。

### 参数与关系

滞后 k 的自相关为 ρ(k)=Cov(y_t,y_(t-k))/Var(y_t)，其中 k 是相隔的采样步数，协方差和方差采用相同的平稳分布。ρ(k) 在 -1 到 1 之间；零相关不等于独立，样本尖峰也不等于稳定预测能力。


### 适用边界与常见误解

样本相关拖尾不能单独证明单位根。
