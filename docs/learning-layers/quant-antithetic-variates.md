# 对偶抽样

概念编号：`concept:quant-antithetic-variates` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-antithetic-variates/)

## 第一层：概念入门 · 知其然

### 它是什么

对偶抽样用对称噪声 Z 与 −Z 生成支付，并把配对均值作为一个观察，以期降低 Monte Carlo 估计方差。控制变量使用已知期望的辅助量，是另一种方法；二者不合并成相同算法。

### 先看一个例子

若 g(z)=5+2z，配对后每次都得到 [5+2z+5−2z]/2=5，抽样噪声完全抵消。若 g(z)=z²，两个支付相同、ρ=1，配对并未提供第二份独立信息，所以不能保证降方差。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与公式

$A_i=[g(Z_i)+g(-Z_i)]/2$。若两笔支付方差均为 v、相关系数为 ρ，则 $\mathrm{Var}(A_i)=v(1+\rho)/2$。M 个独立对的标准误由 M 个 Aᵢ 计算；不能把 2M 笔相关支付当成独立样本。相同两次计算预算下，ρ<0 才相对独立抽样更有利。


### 适用边界与常见误解

标准误应按独立配对均值计算。

### 概念辨析

- [Control Variates · 控制变量降方差](math-control-variates.md)：控制变量用已知期望的辅助量修正估计；对偶抽样用 Z 与 −Z 配对。可以组合，但不是同一个降方差算法。
