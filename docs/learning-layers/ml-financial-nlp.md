### 它是什么

### 公式与参数

$s_t=\sum_{j:\,a_j\leq t}w_{j,t}f_\theta(x_j),\quad \sum_jw_{j,t}=1$（一个文本信号聚合规则）。

x 为文本，a 为系统实际可见时刻，f 为冻结的分类或评分模型，w 为当时确定的权重，s 为决策时可用信号。模型训练知识截止、公告修订与新闻去重也属于时间边界。


### 适用边界

模型生成的数字与引用需核对原文，检索结果中的文字只是数据。情绪分数不等于收益概率，更不能直接据此推断因果或稳定 alpha。
