# 因子暴露

概念编号：`concept:quant-factor-exposure` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-factor-exposure/)

## 第一层：概念入门 · 知其然

### 它是什么

因子暴露衡量资产或组合对某个指定共同因子的敏感程度。在线性收益模型 r=Bf+ε 中，B 为暴露矩阵，f 为因子回报；组合暴露为 Bᵀw。它与作为模型输入的原始财务特征、预测分数并不自动相同。

### 先看一个例子

例子：两个资产的市场 beta 为 1、2，组合权重为 60%、40%，市场暴露为 0.6×1+0.4×2=1.4。若只讨论此线性因子、市场收益为 1%，因子贡献约为 1.4%；这不包含截距、特异残差和交易成本。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 同一个词可能代表四个对象

预测特征是决策时可用的输入，如过去动量；风险暴露是资产对某种共同风险的敏感度；因子收益是一组规定投资组合或风险来源的实现回报；alpha 是相对于指定模型未解释的部分。先区分对象，才知道是在排序股票、解释风险还是估计收益。


### 截面与时间序列的方向

截面研究在同一日期比较不同资产，问哪一只相对表现更好；时间序列研究用一只或一组资产的历史判断其未来绝对或相对状态。二者的数据切分、标准化与评价不同。每只股票各自长期偏高的特征，未必能直接拿来比较同日股票。


### 适用边界与常见误解

不同于某日预测特征分数。
