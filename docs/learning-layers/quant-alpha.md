# 相对模型未解释收益

概念编号：`concept:quant-alpha` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-alpha/)

## 第一层：概念入门 · 知其然

### 它是什么

Alpha 是相对于指定基准模型、长期平均未被解释的收益部分。它依赖采用什么基准、怎样估计以及是否扣除费用。

### 先看一个例子

老师按学生的基础水平预测成绩，再看实际成绩高出预测多少。某一次高出预测可能只是运气；多次、可复核的差异才有助于研究持续效果。金融里的收益模型也不能把一次残差直接叫作长期 alpha。

### 理解练习

某个月组合比模型预测多赚了 1%，就证明有稳定 alpha 吗？

<details><summary>答案与解释</summary>

不能。单期残差包含噪声；长期截距需要在明确模型和费用口径下估计，还要检查遗漏风险与统计不确定性。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 原理与推演

Alpha 是相对于指定基准模型未被解释的收益部分。在 yₜ=α+βᵀfₜ+εₜ 中，α 是截距，y 为组合超额收益，f 为基准因子回报，β 为暴露，ε 为残差；更换模型与费用口径会改变 alpha。


### 收益分解的例子

若一个月市场超额收益 2%，组合市场 beta=1.2，线性模型解释 2.4%；组合超额收益 3% 时残差为 0.6%。这只是该期模型残差，不等于长期回归截距，更不能立即称作技能；遗漏风险、噪声和费用都可能在其中。


### 研究因子与实际策略

French 数据库的因子有指定资产池、分组、币种与权重规则，不能拿任意“价值打分”就称为同一个因子。复制其理论收益还要处理数据可得性、借券和成本。公开因子是基准与研究对象，不是未来业绩承诺。


### 适用边界与常见误解

单期残差不等于已证实的长期技能。

### 概念辨析

- [Return Residual · 收益残差](quant-return-residual.md)：回归 alpha 是指定模型的截距；单期收益残差是该期未解释部分，不能直接视为相同收益。
