# 傅里叶期权定价

概念编号：`concept:pricing-fourier` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/pricing-fourier/)

## 第一层：概念入门 · 知其然

### 它是什么

傅里叶定价把支付函数和风险中性价格分布变换到频域。在分布密度难直接计算、但特征函数易得到时，可以通过数值积分或快速傅里叶变换计算价格。

### 先看一个例子

若 X 服从均值 m=4、方差 v=0.09 的正态分布，φ(1)=exp(4i−0.045)，其模为 exp(−0.045)≈0.956。定价程序可先核对 φ(0)=1，再核对简单模型的已知期权价格。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$\phi_T(u)=E_Q[e^{iuX_T}],\qquad X_T=\log S_T,\qquad V_0=e^{-rT}E_Q[g(e^{X_T})]$。

φ 的通用定义见特征函数基础页。若 φ 可积，密度反演为 $f_X(x)=(2\pi)^{-1}\int_{-\infty}^{\infty}e^{-iux}\phi_T(u)du$，再计算 $V_0=e^{-rT}\int g(e^x)f_X(x)dx$。u 是频率，i²=−1，g 是支付。Carr–Madan 等直接变换支付时，还需控制阻尼和矩存在区间。


### 适用边界

阻尼参数必须落在矩存在的区间。截断、网格间距和别名误差需要收敛检查；FFT 计算快并不意味着误差自动小。
