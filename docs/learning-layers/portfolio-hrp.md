# 层次风险平价

概念编号：`concept:portfolio-hrp` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/portfolio-hrp/)

## 第一层：概念入门 · 知其然

### 它是什么

层次风险平价先按资产相似性聚类，再沿聚类树递归分配风险。它使用相关与协方差信息，但避免直接求整个协方差矩阵的逆，目标也不同于普通最小方差优化。

### 先看一个例子

两个子簇方差分别为 0.01、0.04，则第一簇分到 0.04/0.05=80%，第二簇 20%。实际算法还要明确簇内逆方差权重、聚类方法和叶序。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$d_{ij}=\sqrt{(1-\rho_{ij})/2},\quad a_A=\frac{V_B}{V_A+V_B},\quad a_B=1-a_A$。

ρ 为相关系数，d 为一种相关距离；V_A、V_B 为两个子簇按指定内部权重计算的方差，a 为这次二分分配的资本比例。递归相乘得到最终资产权重。


### 适用边界

不同聚类与叶排序会得到不同组合。HRP 一般不保证每个资产的波动风险贡献相等，不能当成等风险贡献的别名。避免矩阵求逆不等于没有估计误差，成本、流动性和风险集中仍需单独检查。
