# 执行报告

概念编号：`concept:quant-execution-report` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-execution-report/)

## 第一层：概念入门 · 知其然

### 它是什么

FIX语义中ExecType描述本次报告原因，OrdStatus描述报告后的订单状态；CumQty是累计成交，LeavesQty是剩余可成交量。一个“收到报告”事件不总是新增成交，不能每次都把CumQty再累加到持仓。具体状态优先级和字段关系应遵守对应协议。

### 先看一个例子

买8股，先成交3股，再收到相同执行ID，不应变成6股。发撤单并收到取消确认后，又到达取消前发生但传输迟到的2股成交，真实总成交应更新到5。它改变资金和仓位，即使会触发限额警报也不能拒记事实；还需与交易方累计量和时间顺序核对。

### 消息原因与订单状态分开

FIX语义中ExecType描述本次报告原因，OrdStatus描述报告后的订单状态；CumQty是累计成交，LeavesQty是剩余可成交量。一个“收到报告”事件不总是新增成交，不能每次都把CumQty再累加到持仓。具体状态优先级和字段关系应遵守对应协议。

收到执行报告不一定意味着发生了新成交。
