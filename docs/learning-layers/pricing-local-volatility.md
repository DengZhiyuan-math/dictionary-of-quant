# 局部波动率

概念编号：`concept:pricing-local-volatility` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/pricing-local-volatility/)

## 第一层：概念入门 · 知其然

### 它是什么

局部波动率模型把瞬时波动率写成当前时间和当前标的价格的确定函数。它让不同状态有不同波动，能够在理想条件下与一整张欧式期权价格曲面相容。

### 先看一个例子

若 C_T=2、C_KK=0.01，则局部方差为 2/(0.5×100²×0.01)=0.04，局部波动率为 20%。这是由价格曲面的期限与曲率共同反推的数，并非直接拿该点 IV 代入。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$dS_t=(r-q)S_tdt+\sigma_{\mathrm{loc}}(t,S_t)S_tdW_t,\quad \sigma_{\mathrm{loc}}^2(T,K)=\frac{C_T+(r-q)KC_K+qC}{\tfrac12K^2C_{KK}}$。

C(T,K) 是当前时点的欧式看涨价格曲面，T 为期限，K 为行权价，下标表示偏导。Dupire 公式假设常数 r、q，价格曲面充分光滑且没有静态套利。


### 例子

在 r=q=0、K=100 的一个曲面点，若 C_T=2、C_KK=0.01，则局部方差为 2/(0.5×100²×0.01)=0.04，局部波动率为 20%。这是由价格曲面的期限与曲率共同反推的数，并非直接拿该点 IV 代入。


### 适用边界

价格的二阶导数对噪声非常敏感。拟合边际价格并不保证模型对未来波动率曲面动态或奇异期权风险的描述正确。
