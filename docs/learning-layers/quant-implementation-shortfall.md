### 它是什么

买单相对决策基准的执行损耗可包含实际成交价偏离、费用和未完成量的机会成本，需注明终点评价规则。卖单符号相反。与市场VWAP接近不代表相对决策价没有损失，也不代表没有冲击；基准选择回答不同业务问题。
