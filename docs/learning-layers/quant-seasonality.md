# 季节性

概念编号：`concept:quant-seasonality` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-seasonality/)

## 第一层：概念入门 · 知其然

### 它是什么

季节性是与重复日历位置有关的统计模式，例如成交量在开盘、午间和收盘附近具有不同的典型水平。它可以出现在均值、波动或成交强度中，不要求每次都完全重复，也不等于存在可获利的价格方向。

### 先看一个例子

过去训练期中，开盘后第一个五分钟的平均成交量为 2000 股，午间同长度时段为 500 股。今天开盘该桶完成后成交 3000 股，相对历史开盘基线高出 1000 股，或为其 1.5 倍；不应直接与午间的 500 股比较并把全部差异解释为异常。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与关系

一个加法基线可写 x_t=s_(b(t))+u_t，其中 x_t 是当前观测，b(t) 是它所属的交易时段，s_b 是仅用历史同类时段估计的典型水平，u_t 是相对基线的偏离。时区、夏令时、半日市和节假日决定哪些时段可比；用于盘中决策的基线不能使用当天尚未出现的全日数据。


### 适用边界与常见误解

夏令时与节假日会改变实际交易窗口，不能机械填补。
