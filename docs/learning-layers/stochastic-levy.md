# 莱维过程

概念编号：`concept:stochastic-levy` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/stochastic-levy/)

## 第一层：概念入门 · 知其然

### 它是什么

莱维过程从零开始，具有平稳独立增量和随机连续性，并可取右连续且有左极限的路径。它容许扩散和跳跃，用来描述连续波动之外的突发变化。

### 先看一个例子

若 λ=3 次/年，半年没有跳跃的概率为 exp(−1.5)≈22.3%。加入布朗项后，即使半年无跳跃，状态仍会连续波动。

### 公式与参数

$X_t=bt+\sigma W_t+\sum_{i=1}^{N_t}Y_i$（有限活动跳跃的一个例子）。

b 为确定性漂移，σ 为扩散系数，W 为布朗运动，N 为强度 λ 的泊松过程，Yᵢ 为独立同分布跳幅；各随机来源在这个构造中相互独立。一般莱维过程还可能有无限多个小跳。


### 适用边界

独立平稳增量是模型假设，不能自动表达波动聚集。股票价格取 exp(X) 时，还须按指数矩调整漂移才能满足指定鞅条件。
