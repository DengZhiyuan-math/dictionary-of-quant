# 阿尔姆格伦–克里斯最优执行

概念编号：`concept:execution-almgren-chriss` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/execution-almgren-chriss/)

## 第一层：概念入门 · 知其然

### 它是什么

Almgren–Chriss 在价格风险与交易冲击之间选择清仓速度。卖得慢通常降低暂时冲击，却增加持仓期间价格波动的风险；风险偏好决定两者的权衡。

### 先看一个例子

若 X=1200、T=1 小时，半小时后剩余 600；风险厌恶提高时，常见解会把更多卖出提前。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$\min_x E[C]+\lambda\mathrm{Var}(C),\quad x(t)=X\frac{\sinh[\kappa(T-t)]}{\sinh(\kappa T)},\quad \kappa=\sqrt{\lambda\sigma^2/\eta}$（连续时间简化模型）。

X 为初始待卖数量，x 为剩余库存，T 为期限，C 为执行成本，σ 为价格扩散系数，η 为线性暂时冲击系数，λ≥0 为风险厌恶。初末条件为 x(0)=X、x(T)=0。


### 例子

当 λ 趋近零时，公式极限是 x(t)=X(1−t/T)。若 X=1200、T=1 小时，半小时后剩余 600；风险厌恶提高时，常见解会把更多卖出提前。


### 适用边界

所写解依赖恒定参数和指定成本模型。成交量约束、随机流动性、离散股数、限价单与非线性冲击需要扩展模型，不能直接套用这一轨迹。
