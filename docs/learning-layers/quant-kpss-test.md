# 平稳性检验

概念编号：`concept:quant-kpss-test` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-kpss-test/)

## 第一层：概念入门 · 知其然

### 它是什么

KPSS 是检验时间序列是否符合给定平稳设定的方法。其零假设是水平平稳或趋势平稳，取决于是否在模型中包含确定趋势；它与以单位根为零假设的 ADF 不同。

### 先看一个例子

若价格的 KPSS 拒绝水平平稳，而差分收益不拒绝，并不能证明收益必定平稳或适合交易；还需检查趋势设定、窗口、结构突变及样本外行为。ADF 和 KPSS 提供不同零假设下的证据。

### 参数与关系

先去掉选定的常数或趋势，得到残差 e_t，令 S_t=Σ从i=1到t的e_i。统计量可写为 ΣS_t²/(T²ω̂²)，其中 T 是样本长度，ω̂² 是考虑序列相关的长期方差估计。统计量大表示偏离零假设，临界值取决于趋势设定，不能套普通正态阈值。


### 适用边界与常见误解

零假设与 ADF 不同，不能互换判读。
