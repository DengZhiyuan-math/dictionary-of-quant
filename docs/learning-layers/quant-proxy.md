# 代理工具

概念编号：`concept:quant-proxy` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-proxy/)

## 第一层：概念入门 · 知其然

### 它是什么

代理工具是用来估计或对冲另一资产风险的相关工具。例如底层现货市场闭市时，可以用仍交易的指数期货更新相关资产估值。相关不表示等价，代理可能遗漏个股、币种和重开盘风险。

### 先看一个例子

若汇率为每欧元 1.18 美元，则约值 57.82 美元；现货重开盘未必落在这个点，需保留估值区间和减风险计划。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与公式

简化估值 P新≈P旧(1+βrH)，其中 P旧 为最后有效价格，rH 为此后代理收益，β 为目标资产对代理的敏感度。若还需换汇，应再按当前汇率换算；代理模型提供的是估计值，不直接等于可交割或可成交价格。


### 例子

一只欧股最后价格 50 欧元，相关代理之后下跌 2%，取 β=1 则新估值约 49 欧元。若汇率为每欧元 1.18 美元，则约值 57.82 美元；现货重开盘未必落在这个点，需保留估值区间和减风险计划。


### 适用边界与常见误解

代理回报不是闭市现货真实可成交回报。
