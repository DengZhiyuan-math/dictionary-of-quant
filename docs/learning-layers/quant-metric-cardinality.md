# 指标基数

概念编号：`concept:quant-metric-cardinality` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-metric-cardinality/)

## 第一层：概念入门 · 知其然

### 它是什么

指标基数是一个指标在标签组合下形成的不同时间序列数量。过多标签组合会增加存储、查询和告警成本。

### 先看一个例子

10 个账户、5 个场所、4 种订单状态可形成 200 个组合；再乘 100 万个订单 ID，规模可能失控。可用聚合指标看拒单率，再由关联 ID 追到具体订单日志。

## 第二层：深入理解 · 知其所以然

### 参数与关系

若标签独立组合，序列数约为各标签取值数量的乘积。例如账户 A 种、场所 V 种、状态 S 种，最多 A×V×S 条。把每笔唯一订单 ID 当作常驻指标标签，会使数量随订单不断增长，逐笔身份更适合放在可检索日志中。


### 适用边界与常见误解

无界订单 ID 标签可能造成巨大资源负担。
