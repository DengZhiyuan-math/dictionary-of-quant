# 非原子执行

概念编号：`concept:quant-non-atomic-execution` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-non-atomic-execution/)

## 第一层：概念入门 · 知其然

### 它是什么

多腿非原子执行是指相关交易请求缺少整体“全部发生或全部不发生”的保证。数据库内的事务可以保护本地记录，却不能使两个独立场所自动提供同样的成交保证。实际执行结果需要按协议与回报逐腿确认。

### 先看一个例子

同时发 A 买入、B 卖出，A 已成交，B 被拒绝，此时确实持有 A 多头。不能回滚本地“组合成功”标志后，就从资金和持仓中删除 A 的成交。应按预设规则补对冲或平仓，并把相应成本计入策略评价。

## 第二层：深入理解 · 知其所以然

### 参数、公式与边界

把两腿的执行状态记作 (f_A,f_B)，即使简化为是否全部成交，也要处理 (0,0)、(1,0)、(0,1)、(1,1)；部分成交时状态更丰富。并发发送减少等待，不等于原子提交。风险预留、去重、撤单与补救流程须依赖真实订单和执行标识。


### 适用边界与常见误解

同时发送不意味着原子。
