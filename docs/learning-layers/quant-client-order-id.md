# 客户订单标识

概念编号：`concept:quant-client-order-id` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-client-order-id/)

## 第一层：概念入门 · 知其然

### 它是什么

客户订单标识是下单方为订单请求分配的身份，用于关联请求、确认、查询和重试。它不同于交易场所分配的订单号，也不同于每次成交的执行标识。

### 先看一个例子

请求 A：买 10 股，发送后超时。原请求可能已被接受，因此重试 A 时必须先按协议去重或查询；直接生成新的请求 B 再买 10 股，可能导致总共买 20 股。

### 参数与关系

唯一性范围需明确账户、会话和保存期限等边界。相同身份与相同内容的重试应按既定协议去重；相同身份却改变方向、数量或价格，应检测为冲突，不能静默当成同一请求。撤改单是否分配新身份还应遵循具体协议。


### 适用边界与常见误解

重试的相同请求与内容不同的新请求须区分。
