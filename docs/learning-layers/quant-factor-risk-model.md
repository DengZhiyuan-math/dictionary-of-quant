# 因子风险模型

概念编号：`concept:quant-factor-risk-model` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-factor-risk-model/)

## 第一层：概念入门 · 知其然

### 它是什么

因子风险模型把资产收益分成共同因子部分与特质部分，用较低维的共同结构估计组合风险。因子可以是经济变量或统计方向；预测收益的信号并不会自动成为合格的风险因子。

### 先看一个例子

若错误地把资产视为独立，会得到 0.025，漏掉共同因子造成的相关风险。

## 第二层：深入理解 · 知其所以然

### 参数、公式与边界

写成 \(r=Bf+\varepsilon\)。若因子与特质项不相关，则 \(\Sigma=B\Sigma_fB^\mathsf{T}+\Sigma_\varepsilon\)；进一步把特质协方差近似为对角 D 时得到常见简化。B 是资产乘因子的暴露矩阵，Σ_f 是因子协方差；组合方差为 wᵀΣw。遗漏共同风险或错误忽略特质相关会改变风险估计。


### 例子

两个资产对单一因子的暴露均为 1，因子方差为 0.04，特质方差各为 0.01 且互不相关，则协方差矩阵是 [[0.05,0.04],[0.04,0.05]]。各持一半时方差为 0.045；若错误地把资产视为独立，会得到 0.025，漏掉共同因子造成的相关风险。


### 适用边界与常见误解

未必覆盖全部残余共同风险。
