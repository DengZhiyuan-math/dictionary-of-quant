# 事件研究与另类数据

概念编号：`concept:research-event-study` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/research-event-study/)

## 第一层：概念入门 · 知其然

### 它是什么

事件研究围绕一个明确事件时点，比较观察收益与基准预期收益，衡量异常表现。另类数据是常规价格财务报表之外的信息来源；它只有在时间戳、授权与覆盖规则清楚时才可用作研究输入。

### 先看一个例子

若公告发生在收盘后，事件窗应从可交易的下一时点开始。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$AR_{i,t}=R_{i,t}-\widehat E[R_{i,t}\mid\mathcal F_{t-1}],\qquad CAR_{[a,b]}=\sum_{t=a}^bAR_{i,t}$。

AR 为异常收益，CAR 为事件窗累计异常收益，a、b 为相对事件日的位置，基准模型应在事先确定的估计窗拟合。事件公布时刻与数据实际可见时刻必须分别记录。


### 例子

公告后两日资产收益分别为 3%、−1%，基准收益为 1%、0.5%，异常收益为 2%、−1.5%，累计为 0.5 个百分点。若公告发生在收盘后，事件窗应从可交易的下一时点开始。


### 适用边界

事件重叠、共同消息、样本选择和多重检验会影响推断。异常收益本身不证明公告造成了该变化，也不自动构成可交易收益。
