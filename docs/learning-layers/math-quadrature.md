# 数值积分

概念编号：`concept:math-quadrature` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/math-quadrature/)

## 第一层：概念入门 · 知其然

### 它是什么

数值积分用有限个函数值近似连续积分。它适合积分表达式已知、但原函数难以直接求出的情况，误差由网格、函数平滑性和积分区间共同决定。

### 先看一个例子

积分 ∫₀¹x²dx 的真值是 1/3。取 n=2 得到 0.375，取 n=4 得到 0.34375，网格加密后误差显著缩小。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$\int_a^bf(x)dx\approx h\left[\tfrac12f(a)+\sum_{j=1}^{n-1}f(a+jh)+\tfrac12f(b)\right],\quad h=(b-a)/n$。

这是复合梯形法，n 是等长小区间的个数，h 是步长。对足够平滑的函数，误差通常随 h² 缩小；尾部截断误差需要另行评估。


### 适用边界

振荡、尖点、无穷区间和高维积分可能需要自适应方法、变换或 Monte Carlo；不能只增加固定网格而忽略问题结构。
