# 随机变量与分布

概念编号：`concept:prob-random-variable` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/prob-random-variable/)

## 第一层：概念入门 · 知其然

### 它是什么

随机变量把随机结果对应成数值；分布描述这些数值出现的概率。变量是计数或测量的规则，分布是结果的不确定性。

### 先看一个例子

投两次硬币，把正面出现次数记成 X。正反顺序有四种结果，而 X 只有 0、1、2 三种取值，X=1 包含“正反”和“反正”。

### 理解练习

X 的取值有三个，是否每个取值都各占三分之一？

<details><summary>答案与解释</summary>

不是。公平且独立时，四种顺序等可能，X=1 对应其中两种，概率为 1/2；X=0 与 X=2 各为 1/4。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 定义

随机变量把一次随机结果映射为一个数；分布描述这个数如何落在不同范围。离散分布使用概率质量，连续分布可用概率密度，但密度的单点高度不是单点概率。


### 公式与参数

$F_X(x)=P(X\le x),\quad E[X]=\sum_xx\,p(x)\ \text{或}\ \int xf(x)dx$。

F 是累计分布函数，p(x) 是离散取值的概率质量，f(x) 是连续密度。期望要求相应的绝对可积条件，方差还要求有限二阶矩。


### 例子

若 X 取 0 和 2 的概率各一半，E[X]=1，但 X 从不等于 1。若 X 在 [0,1] 均匀分布，则 P(X=0.5)=0，而 P(0.4≤X≤0.6)=0.2。


### 适用边界

概率密度可以大于 1；概率由对区间积分得到，并始终在 0 与 1 之间。


### 适用边界与常见误解

概率密度可以大于 1；概率由对区间积分得到，并始终在 0 与 1 之间。
