# 随机变量与分布

概念编号：`concept:prob-random-variable` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/prob-random-variable/)

## 第一层：概念入门 · 知其然

### 它是什么

随机变量给每种可能结果一个数值；分布说明这些数值各有多大可能出现。

### 先看一个例子

掷硬币时正面记1、反面记0，公平硬币两值各占一半。

### 理解练习

随机变量就是每次抽到的那个数吗？

<details><summary>答案与解释</summary>

随机变量是编码规则，观测值是规则在一次试验中的结果。

</details>

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 从条件一步步推导

1. 离散分布的概率p(x)满足p(x)≥0、Σp(x)=1。
2. 均值是概率加权和E[X]=Σxp(x)，方差为E[X²]−E[X]²。

### 具体输入与计算步骤

X取0、2、4，概率分别0.25、0.5、0.25。

1. E[X]=0+1+1=2，E[X²]=0+2+4=6。
2. Var(X)=6−2²=2。

计算结果：均值2，方差2。

### 换到实际问题中应用

库存缺货损失为L=max(X−2,0)，用上述需求分布估算。

1. 需求0、2、4对应损失0、0、2。
2. 期望损失0.25×0+0.5×0+0.25×2=0.5。

应用结论：平均缺货量0.5单位。

### 举一反三：改变条件后的完整解答

若Y=3X+1，其均值和方差是多少？

<details><summary>变式的推演与答案</summary>

1. 均值3E[X]+1=7。
2. 方差3²Var(X)=18，常数平移不改变方差。

E[Y]=7、Var(Y)=18。

</details>

### 原有解释与进一步例题


### 定义

随机变量把一次随机结果映射为一个数；分布描述这个数如何落在不同范围。离散分布使用概率质量，连续分布可用概率密度，但密度的单点高度不是单点概率。


### 公式与参数

$F_X(x)=P(X\le x),\quad E[X]=\sum_xx\,p(x)\ \text{或}\ \int xf(x)dx$。

F 是累计分布函数，p(x) 是离散取值的概率质量，f(x) 是连续密度。期望要求相应的绝对可积条件，方差还要求有限二阶矩。


### 例子

若 X 取 0 和 2 的概率各一半，E[X]=1，但 X 从不等于 1。若 X 在 [0,1] 均匀分布，则 P(X=0.5)=0，而 P(0.4≤X≤0.6)=0.2。


### 适用边界

概率密度可以大于 1；概率由对区间积分得到，并始终在 0 与 1 之间。


### 适用边界与常见误解

概率密度可以大于 1；概率由对区间积分得到，并始终在 0 与 1 之间。
