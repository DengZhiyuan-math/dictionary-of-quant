# 费曼–卡茨公式

概念编号：`concept:stochastic-feynman-kac` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/stochastic-feynman-kac/)

## 第一层：概念入门 · 知其然

### 它是什么

费曼–卡茨公式在适当正则条件下，把带终端条件的偏微分方程解表示为扩散过程未来支付的折现期望。它解释了为什么模拟路径和求解定价方程可以计算同一个量。

### 先看一个例子

若期末固定支付 50，r=4%、剩余期限半年，u=50exp(−0.02)≈49.01；因为支付与 X 无关，空间导数为零，方程简化为 uₜ−ru=0。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 公式与参数

$u_t+\mu u_x+\tfrac12\sigma^2u_{xx}-ru=0,\ u(T,x)=g(x),\quad u(t,x)=E[e^{-r(T-t)}g(X_T)\mid X_t=x]$。

X 满足 dX=μdt+σdW，g 是终端支付，r 此处为常数折现率，u 是当前价值。金融应用中，漂移和期望必须使用同一个指定定价测度。

边界、增长条件及解的正则性都重要。提前行权需要最优停止或障碍问题，不能直接只算一次终端期望。
