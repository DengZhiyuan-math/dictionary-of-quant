# 预期边际

概念编号：`concept:quant-edge` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-edge/)

## 第一层：概念入门 · 知其然

### 它是什么

预期边际是某一侧成交后的条件价值与成交价之差，再减去尚未包含的成本；它是事前期望，不保证本次实现盈利。

### 先看一个例子

例子：假设条件公允价值为 100，买价 99.98、单位费用 0.01，则该买侧即时模型边际为 100−99.98−0.01=0.01。若成交本身让条件估值降为 99.95，边际变为 −0.04；报价离中价有利不保证成交后有利。

### 每侧经济性怎样检查

对单次 bid 成交，预期边际约为成交后的条件价值-Bid-成本；ask 成交则是 Ask-条件价值-成本。若每侧 hedge 0.04、信息损失预算 0.03、目标收益 0.02，则 h=0.09，示意 99.91/100.09。


### 适用边界与常见误解

单次正期望不保证单次盈利。
