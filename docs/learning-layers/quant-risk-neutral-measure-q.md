# 风险中性测度

概念编号：`concept:quant-risk-neutral-measure-q` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-risk-neutral-measure-q/)

## 第一层：概念入门 · 知其然

### 它是什么

真实测度 P 描述实际结果的概率，研究预期收益、回测和风险频率通常在此进行。定价测度 Q 是在给定模型中用于无套利估值的等价测度；无分红标的按现金账户贴现后在 Q 下为鞅。含分红时需处理再投资或累计收益，不能直接把除息价格也当成相同贴现鞅。

### 先看一个例子

假设。随机波动或不可对冲跳跃通常引入额外风险源。选择 Q、估计风险溢价和对冲误差是不同问题；不能把“把 μ 换成 r”当作所有模型的普遍定价方法。

### 风险中性期望的表示

在适用条件下 V(t,S)=E_Q[e^(-rτ)g(S_T)|F_t]。相同初始股票、波动和利率下，投资者把真实 μ 从 8% 改为 15%，并不会直接改变该可复制模型的欧式期权价格。因为风险已通过交易复制，不能再额外要求主观股票收益率折现同一支付。


### 不完备市场的边界

这一推理依赖连续交易、无摩擦、可借贷及扩散风险可复制等假设。随机波动或不可对冲跳跃通常引入额外风险源。选择 Q、估计风险溢价和对冲误差是不同问题；不能把“把 μ 换成 r”当作所有模型的普遍定价方法。

### 概念辨析

- [Risk Neutral Probability · 风险中性概率](quant-risk-neutral-probability.md)：风险中性测度规定整套事件或路径的定价权重；风险中性概率可以指该测度下某个离散分支的权重。一个二叉树上行概率不是完整测度的全部内容，也不是实际上涨概率。
