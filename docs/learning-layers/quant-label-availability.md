# 标签可用时间

概念编号：`concept:quant-label-availability` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-label-availability/)

## 第一层：概念入门 · 知其然

### 它是什么

金融样本通常记录资产、决策时刻、当时可用特征和之后实现的目标。预测下一日收益与未来五日收益是不同任务；目标所属日期不等于目标已经可见的日期。标签可用时间，是完整目标已经实现、且研究系统已收到所需数据的最早时刻。

### 先看一个例子

交易日 0 收盘价为 100，交易日 5 收盘价为 102，五日标签为 2%。交易日 2 训练模型时，这个标签尚未完成，不能把最终的 2% 写入训练集。交易日 5 收盘后还要等待价格确认和数据接收。连续日期的五日标签还会共享收益区间，不能因为有很多行就把它们视为独立证据。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与时间边界

设决策时刻为 t、预测期限为 h，以价格 P 定义简化收益标签 \(y_t=P_{t+h}/P_t-1\)；分红等现金流需另按标签契约处理。设该标签实际可用时刻为 a_t、拟合时刻为 T，则训练只能使用 a_t≤T 的样本，同时要求特征在 t 时已经可用。h 是预测跨越的时间，不是模型训练次数。


### 适用边界与常见误解

标签起点早于决策时间仍可能尚未结束。
