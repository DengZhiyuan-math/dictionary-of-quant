# 贝塔敏感度

概念编号：`concept:quant-beta` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-beta/)

## 第一层：概念入门 · 知其然

### 它是什么

金融 beta 是资产收益对指定基准收益的线性敏感度。在线性回归中，它是基准收益的系数；beta=1.2 表示模型估计基准变动 1% 时，该资产的相关收益部分约变动 1.2%，不保证每次都如此。

### 先看一个例子

持有市值 200,000 元、beta=1.2 的 ETF，指数风险名义约为 240,000 元。单张期货名义为 60,000 元时，可用卖出 4 张抵消该线性指数风险，仍有估计误差和基差风险。

### 参数与公式

若基准方差大于零，β=Cov(r资产,r基准)/Var(r基准)。带符号市值 N 的 beta 风险名义为 βN。必须统一收益频率、币种和估计窗口；这里的 beta 与描述概率参数的 Beta 分布不同。


### 适用边界与常见误解

不同于相关系数，也不概括全部尾部风险。
