# 真实概率测度

概念编号：`concept:quant-physical-measure-p` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-physical-measure-p/)

## 第一层：概念入门 · 知其然

### 它是什么

真实概率测度 P 描述实际世界中各结果发生的概率，用于研究预期收益、历史风险频率和策略表现。它需要从数据与假设估计，不是已知不变的真值表。

### 先看一个例子

若无套利复制给出定价权重 62.5%，不能直接拿 80% 替换后者去给可复制期权定价。

### 参数与公式

真实模型可写 dS=μSdt+σSdWᴾ，μ 是真实世界的漂移，σ 是扩散波动，Wᴾ 是 P 下的布朗运动。预期收益 Eᴾ[r] 与无套利定价中的 Eᑫ[支付] 回答不同问题。


### 例子

某一步模型估计实际上涨概率 80%，这可用于预测投资结果；但若无套利复制给出定价权重 62.5%，不能直接拿 80% 替换后者去给可复制期权定价。


### 适用边界与常见误解

不同于用于无套利估值的 Q。
