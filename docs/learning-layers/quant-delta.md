# 一阶价格敏感度

概念编号：`concept:quant-delta` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-delta/)

## 第一层：概念入门 · 知其然

### 它是什么

Delta 是期权价值对标的价格的一阶局部敏感度，表示其他输入暂不变时，标的价格小幅变化对期权价值的近似影响。它是导数，不应直接解释成真实世界的上涨概率。

### 先看一个例子

100 份多头看涨、乘数 100、Delta=0.6，股票等价为 +6,000 股，可用卖出 6,000 股建立局部 Delta 中性。标的只小涨 1 元时，期权组合的一阶价值变化约为 +6,000 元。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 参数与公式

Δ=∂V/∂S，小变动近似 ΔV≈Δ·ΔS。V 为每单位期权价值、S 为标的价格；n 份期权、每份乘数 m 的股票数量等价为 nmΔ。对冲该方向风险可配置 -nmΔ 股，但 Delta 随价格和时间改变。


### 适用边界与常见误解

delta 中性不消除 gamma 或 vega。
