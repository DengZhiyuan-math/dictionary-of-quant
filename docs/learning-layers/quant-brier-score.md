# 布里尔分数

概念编号：`concept:quant-brier-score` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-brier-score/)

## 第一层：概念入门 · 知其然

### 理解这个概念所需的背景

概率预测必须说明事件，如“下一交易日收盘收益为正”。它不同于预测收益金额；即使预测80%，一次事件未发生也不直接证明该概率错误。


### 定义

二元事件的布里尔分数是预测概率与0/1结果之差的平方的样本平均：事件发生记1，否则记0。分数越小越好；它同时受到概率校准和区分不同风险情形能力的影响。

### 概念边界与常见混淆

比较应使用相同事件、样本和评分约定。布里尔分数不包括涨跌幅、执行或成本，因此更好的分数不自动带来更高收益。

### 先看一个例子

两次预测概率0.8、0.6，实际结果1、0。平方误差分别(0.8−1)²=0.04、(0.6−0)²=0.36，平均0.20。固定报0.5的模型两次都为0.25，本小样本评分较差，但不足以断言长期优劣。

## 第二层：深入理解 · 知其所以然

围绕推导、计算、应用与推广阅读；下面保留原有推演顺序。

### 从条件一步步推导

1. 对一次二元事件，平方误差为(p−y)²；对固定数据集再取平均。
2. 若真实概率为q，期望平方损失=q(1−p)²+(1−q)p²，求导得最优p=q。

### 具体输入与计算步骤

报80%而事情发生，误差较小；报60%而没发生，误差较大。

1. 概率0.8、0.6，结果1、0，平方误差为0.04与0.36。
2. 平均(0.04+0.36)/2=0.20；恒报0.5得0.25。

计算结果：本例分数改善0.05，不构成稳定概率优势的充分证据。

### 换到实际问题中应用

评价下一日上涨概率。

1. 固定事件、期限和日期集，比较基线与校准图，同时另算成本后交易结果。

应用结论：概率评分和资金损益各按正确口径报告。

### 原有解释与进一步例题


### 定义与应用范围

二元 Brier 分数是预测概率与实际二元结果之间的平均平方差。金融方向预测中，标签可以是某个规定期限的收益是否大于零；它评价概率质量，不是比较收益预测值与实际收益，也不直接给出交易盈利。


### 参数、公式与边界

对 N 个已完成标签，\(BS=N^{-1}\sum_{i=1}^{N}(p_i-y_i)^2\)，p_i∈[0,1]，y_i∈{0,1}，越低越好。结果范围为 0 到 1。标签期限、样本权重及评价时间段须固定；重叠标签会影响统计不确定性。校准和排序是不同性质，不能由一个总体分数替代全部诊断。


### 例子

两次预测为 0.8、0.6，结果分别为 1、0，则 BS=(0.04+0.36)/2=0.20。恒报 0.5 的基线在同两次上的分数是 0.25。这个示例只说明平方评分变好，不能据此认定扣除成本后应该交易，也不能用这两个观测证明稳定优势。


### 适用边界与常见误解

同时受区分度与校准等影响，不是纯校准指标。
