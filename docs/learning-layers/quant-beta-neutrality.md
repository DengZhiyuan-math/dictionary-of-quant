# 市场beta中性

概念编号：`concept:quant-beta-neutrality` · [网站双语阅读](https://zhiyuan-deng.pages.dev/dictionary/topic/concept/quant-beta-neutrality/)

## 第一层：概念入门 · 知其然

### 它是什么

市场 beta 中性要求组合对一个指定市场因子的估计线性暴露接近零。它把单个资产的 beta 用到多空组合约束；beta 依赖所选基准和估计窗口，金额中性与 beta 中性不能互相替代。

### 先看一个例子

多头名义 100 元、beta=2，空头名义 −100 元、beta=1，净名义是零，但净 beta 名义为 100 元。只调整空腿时，要空 200 元才在此模型下抵消 beta；此时净名义为 −100 元。两条约束是否同时可行，取决于可用资产及其他限制。

### 参数、公式与边界

有符号名义为 N_i、对应市场敏感度为 β_i，则净 beta 名义为 \(B_N=\sum_iN_i\beta_i\)。约束是 B_N 接近零，而金额中性约束是 ΣN_i 接近零。各腿必须统一币种、方向与基准；估计误差与关系变化使“估计为零”不同于真实风险消失。


### 适用边界与常见误解

beta会变化，中性也不消除其他风险。
